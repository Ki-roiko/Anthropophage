# Anthropophage

3D-игра от первого лица на Godot 4 (проект «3d voxel»).

## Запуск

1. Откройте `project.godot` в Godot (версия указана в `config/features` файла `project.godot`).
2. Убедитесь, что включён плагин **Terrain3D** (*Project → Project Settings → Plugins*).
3. Главная сцена — `scenes/world.tscn`.

## Управление

| Действие | Клавиша |
|---|---|
| Движение | W / A / S / D |
| Прыжок | Space |
| Спринт | Shift |
| Инвентарь | Tab |
| Взаимодействие / подбор | E |
| Взять предмет из инвентаря в руки | Двойной щелчок ЛКМ по предмету |
| Отпустить предмет из рук | F |
| Перемещение предмета в сетке | Зажать ЛКМ и перетащить |
| Повернуть предмет при переносе | R |
| Выбросить предмет из инвентаря | ПКМ по предмету |
| Физический захват объекта | Удерживать ЛКМ на подходящем RigidBody3D |
| Освободить мышь | Esc (клик по окну возвращает захват) |

## Структура

- `scenes/` — сцены (мир, игрок, ландшафт, UI); `scenes/terrain_data/` — данные регионов Terrain3D
- `scripts/player.gd` — контроллер игрока (движение, выносливость, эффекты камеры)
- `scripts/inventory/` — модель инвентаря и интерфейс сетки
- `resources/items/` — описания предметов в формате Resource
- `scripts/player_interaction.gd` — подбор, выбрасывание и предмет в руках
- `scripts/physics_grab.gd` — отдельная физическая система захвата объектов
- `scenes/items/` — сцены физических предметов и объектов для захвата
- `scenes/ui/stat_bar.gd` — универсальная шкала (`StatBar`) для здоровья и выносливости
- `addons/` — Terrain3D и Zylann Voxel Tools (GDExtension)
- `models/`, `textures/` — ассеты

## Система инвентаря и предметов

Полное руководство по созданию отдельных `ItemDefinition` находится в [resources/items/README.md](resources/items/README.md). Ниже — карта системы и правила её расширения.

### Поток данных

`ItemDefinition (.tres)` → `InventoryDataModel` → `InventoryUIController` → `WorldItem / PlayerInteraction`.

- `resources/items/item_definition.gd` описывает неизменяемые данные типа предмета: ID, размер в клетках, стек, отображение, mesh и массу.
- `scripts/inventory/inventory_data.gd` — единственный источник состояния инвентаря. Экземпляр содержит `uid`, `item_id`, `amount`, `position` и `rotated`.
- `scripts/inventory/inventory_ui.gd` отвечает только за ввод и отрисовку. Он не изменяет массив предметов напрямую: перемещение выполняется через `InventoryDataModel.move_item()`.
- `scripts/world_item.gd` представляет подбираемый физический предмет. `interact(player)` вызывает `add_item()` и оставляет в мире остаток, который не поместился.
- `scripts/player_interaction.gd` выполняет raycast из камеры, подбор по E, выброс, а также показ предмета в руках.
- `scripts/physics_grab.gd` работает только с подходящими `RigidBody3D`, которые не входят в группу `world_pickup`.

### Добавление нового предмета

1. Создайте `.tres` на основе `ItemDefinition` в `resources/items/`.
2. Зарегистрируйте его в `ITEM_DEFINITIONS` в `scripts/inventory/inventory_data.gd`; `item_id` в ресурсе и ключ словаря должны совпадать.
3. Выберите размер `Vector2i`: например, 1×1, 1×2 или 2×2. Поворот меняет X и Y местами.
4. Для предмета в мире создайте экземпляр `scenes/items/world_item.tscn`, укажите `item_id` и `amount`.
5. Проверьте подбор, полный стек, неполный стек, поворот у края сетки и выброс в мир.

### Контракты и безопасная модернизация

- Не изменяйте `_items` снаружи `InventoryDataModel`; используйте `add_item`, `remove_item`, `can_place` и `move_item`.
- После любого изменения данных модель посылает `inventory_changed`; UI обновляется по этому сигналу.
- `add_item()` возвращает остаток. Его нужно сохранить в мире, а не удалять.
- `move_item()` сам запрещает выход за границы и пересечения, поэтому UI может только показать валидность предварительного размещения.
- Для сохранений сериализуйте `get_items()` и `_next_uid`; при загрузке восстанавливайте оба значения до показа UI.
- Для новых действий UI добавляйте отдельный signal, а обработку мира оставляйте в `player_interaction.gd`.
- Физические предметы должны сохранять `CollisionShape3D`, `continuous_cd`, layer 2 и mask 3, иначе они не будут надёжно сталкиваться с Terrain3D и друг с другом.

### Быстрый регресс-чек

1. Открыть и закрыть инвентарь Tab: курсор появляется, игрок и камера не управляются.
2. Перетащить 1×1, 1×2 и 2×2: зелёная подсветка разрешает размещение, красная запрещает.
3. Повернуть 1×2 во время drag: карточка остаётся под той же точкой курсора, а итоговое положение не пересекает другие предметы.
4. Подобрать полный и частично помещающийся стек: остаток остаётся в мире.
5. Выбросить и снова подобрать предмет; убедиться, что он физически падает на Terrain3D.
6. Захватить ящик ЛКМ и провести его к стене: ящик должен упереться, а не пройти сквозь неё.
