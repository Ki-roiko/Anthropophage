# Добавление предметов

Инвентарь использует ресурсы ItemDefinition в этой папке. Данные предметов не смешаны с кодом сетки или интерфейса.

## 1. Создать ресурс

В Godot создайте новый Resource на основе ItemDefinition и сохраните его, например, как resources/items/keycard.tres.

Заполните поля:

- item_id — уникальный ID, например keycard.
- display_name и description — имя и описание.
- size — размер в клетках: Vector2i(1, 1), Vector2i(1, 2), Vector2i(2, 2) и т. п.
- max_stack_size — максимальное количество в одном стаке.
- icon_symbol — символ для карточки предмета в UI.
- display_color — цвет карточки и простого меша в мире.
- world_mesh — Mesh, который показывается в мире и в руках.
- weight — масса одной штуки; используется также при создании физического предмета.

Размер инвентаря — 8×6 клеток. Поворот меняет местами X и Y автоматически.

## 2. Зарегистрировать ресурс

Откройте scripts/item_catalog.gd и добавьте одну запись в `DEFINITIONS`:

	&"keycard": preload("res://resources/items/keycard.tres"),

ID в словаре должен совпадать с item_id внутри ресурса.

## 3. Добавить предмет в мир

Создайте экземпляр scenes/items/world_item.tscn в нужной сцене и задайте ему item_id и amount. Сцена сама возьмёт меш, цвет и вес из ItemDefinition.

Предметы реализуют интерфейс interact(player). Для нового интерактивного объекта можно реализовать такой же метод и, при необходимости, метод get_interaction_prompt(). Скрипт игрока ищет этот метод по лучу из камеры.

## 4. Изменить физический захват

Физически захватываются RigidBody3D, которые не входят в группу world_pickup, не заморожены и не превышают max_grab_mass в PhysicsGrab. Для тяжёлых или неподвижных объектов можно изменить mass, freeze и collision layer/mask.

## Управление

- Перекрестие в центре экрана показывает направление луча взаимодействия.
- Tab — открыть / закрыть инвентарь.
- ЛКМ по предмету в инвентаре — начать перемещение. Карточка плавно следует за курсором; клетки под будущим размещением подсвечиваются зелёным или красным. Отпустите ЛКМ, чтобы зафиксировать предмет в допустимой клетке.
- R во время перемещения — повернуть предмет.
- ПКМ по карточке — выбросить весь стак.
- Двойной ЛКМ по карточке — взять одну штуку в руки.
- E — взаимодействовать с объектом перед камерой / подобрать предмет.
- F — отпустить предмет из рук.
- Удерживать ЛКМ на физическом объекте — захватить и перемещать его.

При подборе предметов, для которых в инвентаре нет места, оставшееся количество остаётся в мире.

## Физические предметы

`scenes/items/world_item.tscn` — подбираемый предмет. Он должен быть `RigidBody3D` с активным `CollisionShape3D`, `continuous_cd = true`, `collision_layer = 2` и `collision_mask = 3`. Это позволяет ему сталкиваться с Terrain3D и другими предметами даже при быстром падении.

Для нового тестового предмета создайте экземпляр этой сцены в `scenes/world.tscn`, задайте `item_id` и `amount` и разместите его выше поверхности. Позиция такого предмета сохраняется в сцене и не меняется скрытым runtime-скриптом.

`scenes/items/physics_crate.tscn` — отдельный физический объект для захвата. Он не входит в группу `world_pickup`, поэтому подхватывается удержанием ЛКМ. Захват прикладывает ограниченную пружинную силу, а не перемещает объект телепортацией; препятствия на пути не позволяют протащить его через стену.
